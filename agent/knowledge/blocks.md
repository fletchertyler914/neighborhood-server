# Minecraft Block IDs (Java Edition)

ALWAYS use exact lowercase namespaced IDs. Vanilla blocks omit the `minecraft:`
prefix safely. NEVER guess — pick from this list. If a block isn't here, ask.

## Stone family
- `stone`, `cobblestone`, `mossy_cobblestone`, `smooth_stone`
- `andesite`, `polished_andesite`, `diorite`, `polished_diorite`, `granite`, `polished_granite`
- `deepslate`, `cobbled_deepslate`, `polished_deepslate`, `chiseled_deepslate`
- `tuff`, `polished_tuff`, `calcite`, `dripstone_block`, `basalt`, `smooth_basalt`
- `stone_bricks`, `mossy_stone_bricks`, `chiseled_stone_bricks`, `cracked_stone_bricks`
- `deepslate_bricks`, `cracked_deepslate_bricks`, `deepslate_tiles`, `cracked_deepslate_tiles`
- `end_stone`, `end_stone_bricks`
- `nether_bricks`, `red_nether_bricks`, `chiseled_nether_bricks`
- `blackstone`, `polished_blackstone`, `polished_blackstone_bricks`, `gilded_blackstone`

## Wood (planks)

## Light sources
- `glowstone`, `sea_lantern`, `shroomlight`, `jack_o_lantern`
- `lantern`, `soul_lantern`, `torch`, `soul_torch`, `redstone_torch`
- `campfire`, `soul_campfire`, `end_rod`, `lava` (avoid in builds)

## Nature
- `grass_block`, `dirt`, `coarse_dirt`, `podzol`, `mycelium`, `moss_block`
- `sand`, `red_sand`, `gravel`, `clay`
- `snow_block`, `ice`, `packed_ice`, `blue_ice`
- `oak_leaves`, `spruce_leaves`, `birch_leaves`, `cherry_leaves`, `pale_oak_leaves`
- `water`, `lava` (use carefully)

## Special / utility
- `air` (use to clear/dig)
- `barrier` (invisible wall, OP only)
- `bedrock` (don't use in builds)
- `command_block` (admin only)

## Common typos to AVOID
- `quartz` -> use `quartz_block` (not `quartz`)
- `wood` -> pick a specific plank (`oak_planks`)
- `stonebrick` -> `stone_bricks`
- `glass_pane` is a pane, not a full block (different shape)
