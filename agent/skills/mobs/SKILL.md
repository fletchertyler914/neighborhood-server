# Mobs skill

Spawn creatures at coordinates.

- Use `summon_entity` with entity id, x/y/z, and count.
- Place mobs near the player position from context unless absolute coords are given.
- For a fenced coop/pen build, that is the **build** skill (`paste_template_at_player`), not this skill.

One tool call only. Any summonable mob is allowed (including bosses).
