# Admin skill

World and player utility — no large builds.

- Time of day → `set_time` (`day`, `night`, `noon`, `midnight`).
- Weather → `set_weather` (`clear`, `rain`, `thunder`).
- Items → `give_item` with a vanilla item id (aliases like pickaxe → diamond_pickaxe are ok).
- Status → `preflight` or `list_players`.

One tool call only.
